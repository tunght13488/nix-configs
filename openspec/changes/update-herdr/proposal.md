## Why

Herdr v0.7.3 is a bugfix release on top of v0.7.2, fixing cursor flicker, Windows memory leaks, workspace picker keybindings, and socket API state issues. v0.7.2 also brings shell completions and new config options. Updating keeps the install current with upstream fixes.

## What Changes

- Bump herdr flake input from `v0.7.1` to `v0.7.3` in `flake.nix`
- Update `flake.lock` to pin the new revision
- Update the `herdr-terminal-multiplexer` spec to reflect the new pinned version
